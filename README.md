# VEIL — Private Finance. Onchain.

Private treasury, payments, and payroll on Solana using Helius Privacy Rings.

## Stack
- Next.js 16 + TypeScript + Tailwind
- Solana Wallet Adapter
- Helius Privacy Rings (`@heliuslabs/zolana`)
- Solana Devnet

## Run locally
```bash
npm install
npm run dev
```
